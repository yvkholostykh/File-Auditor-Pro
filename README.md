## 🎯 О программе / About

**FILE AUDITOR PRO** — это профессиональный инструмент для информационной безопасности, предназначенный для **поиска конфиденциальной информации** (ПДн, договоры, пароли, документы с ключевыми словами) в файловой системе и **форензик-аудита** дисков, USB-носителей и сетевых ресурсов.

> **Главные принципы:**
> - 🚀 **GUI стартует мгновенно** — библиотеки устанавливаются в фоне
> - 🧠 **Умная установка** — многопоточная, с fallback-аналогами
> - 🔍 **Глубокий анализ** — от PDF до CAD, от EML до реестра
> - 📊 **Полноценный отчёт ИБ** — с обобщёнными выводами, метриками и детальными карточками
> - ⚡ **Режим «только имена»** — сверхбыстрая проверка без извлечения содержимого

## ⚙️ Установка / Installation

### Требования

| Компонент | Требование |
|---|---|
| **ОС** | Windows 10 / 11 (x64) |
| **Python** | 3.8 – 3.12 |
| **Память** | от 4 ГБ (для OCR — от 8 ГБ) |
| **Диск** | от 500 МБ (плюс ~2 ГБ для EasyOCR + Torch) |

### Шаг 1. Установите Python

Скачайте с [python.org](https://www.python.org/downloads/) и при установке отметьте:
- ✅ **Add Python to PATH**
- ✅ **Install for all users**

### Шаг 2. Скопируйте файл

```powershell
git clone https://github.com/yvkholostykh/file-auditor-pro.git
cd file-auditor-pro
```

Или просто скачайте `File Auditor Pro v40.7.py` в отдельную папку.

### Шаг 3. Запустите

```powershell
python "File Auditor Pro v40.7.py"
```

> 💡 **Первый запуск:** программа автоматически:
> 1. Создаст папку `libs/` и установит туда все зависимости (в фоне)
> 2. Создаст `keywords.txt` с базовым списком ключевых слов
> 3. Создаст `auditor_settings.json` с настройками
> 4. Создаст папку `~/FileAuditorReports/` для отчётов

**Никаких `pip install` вручную не требуется** — всё ставится автоматически.

### Опционально: Tesseract-OCR

Для распознавания изображений без EasyOCR установите [Tesseract-OCR](https://github.com/UB-Mannheim/tesseract/wiki):

```powershell
# После установки укажите путь к tesseract.exe в переменной PATH
# или положите его в одну из стандартных папок:
# C:\Program Files\Tesseract-OCR\
# C:\Program Files (x86)\Tesseract-OCR\
```

### Опционально: 7-Zip / WinRAR

Для работы с **RAR-архивами** нужен внешний распаковщик:

```powershell
winget install 7zip.7zip
```

## 🚀 Быстрый старт / Quick Start

### 1️⃣ Первый запуск

При запуске появится сплэш-окно с информацией о программе — нажмите **OK**.

### 2️⃣ Дождитесь установки библиотек

На вкладке **Библиотеки** будет виден прогресс установки. **GUI уже доступен** — установка идёт в фоне.

### 3️⃣ Выберите цель сканирования

| Кнопка | Действие |
|---|---|
| **📁 Папка...** | Сканировать одну папку (рекурсивно) |
| **💾 Выбрать диски…** | Открыть диалог выбора дисков (внутренние / USB / все) |

### 4️⃣ Настройте режим

| Кнопка | Назначение |
|---|---|
| **🔊 Звук: ВКЛ** | Звуковой сигнал при находке |
| **📝 Только имена** | Сверхбыстрый режим — проверка только имён файлов (без содержимого) |
| **🌐 Язык: RU** | Переключение RU ↔ EN |

### 5️⃣ Запустите сканирование

Нажмите **📁 Папка...** или **💾 Выбрать диски…** и выберите цель.

### 6️⃣ Дождитесь завершения

Наблюдайте прогресс:
- **Счётчики**: найдено / проверено / прошло
- **Прогресс-бар**: с процентами и оставшимся временем
- **Журнал**: цветные события (🟢 успех / 🔴 ошибка / 🟡 предупреждение / 🟣 находка)

### 7️⃣ Экспортируйте отчёт

| Кнопка / меню | Результат |
|---|---|
| **📄 Экспорт TXT** | Полный текстовый отчёт |
| **📝 Экспорт WORD** | Word-отчёт с кликабельными ссылками |
| **Файл → Экспорт WORD (разбить по 100 стр.)** | Несколько файлов для больших объёмов |

## 🗂️ Работа с чекпоинтами / Checkpoints

### Что это?

Если сканирование было **прервано** (кнопка Стоп, сбой питания, падение), состояние сохраняется в `audit_checkpoint.json`. При следующем запуске программа **продолжит с того же места**.

### Управление

| Действие | Где |
|---|---|
| **Просмотр информации** | Меню «Инструменты → Информация о чекпоинте» |
| **Сброс** | Меню «Инструменты → Сбросить чекпоинт» |
| **Автосохранение** | Каждые 100 файлов или 5 секунд |
| **Автоудаление** | При успешном завершении сканирования |

### Пример окна информации

```
Файл чекпоинта: D:\FileAuditorPro\audit_checkpoint.json
Файл существует: Да
Версия: 40.7 GUI

Цели: D:\Документы
Обработано файлов: 1234
Сохранено результатов: 42
Всего файлов: 5678
Начат: 15.01.2025 10:22:33
Сохранён: 15.01.2025 10:35:12
```

- **Обобщённые выводы** (категории, топ-15 расширений, ключевые слова, владельцы, авторы)
- **Форензик-метрики**
- Детальные карточки по каждому файлу

### 📄 WORD-отчёт

- Титульный лист с данными офицера ИБ
- Сводка и обобщённые выводы
- Информация о носителях

## ❓ FAQ

<details>
<summary><b>❓ Программа долго запускается в первый раз</b></summary>

При первом запуске идёт установка библиотек. Это нормально — на медленном интернете может занять 10–30 минут. GUI при этом **уже доступен**, можно сразу начинать сканирование.

</details>

<details>
<summary><b>❓ OCR не работает</b></summary>

Проверьте:
1. Вкладка **Библиотеки** — установлены ли EasyOCR / pytesseract
2. Для Tesseract — установлен ли `tesseract.exe` (см. раздел «Опционально»)
3. Для EasyOCR — скачаны ли модели (при первом запуске скачиваются ~64 МБ)

</details>

<details>
<summary><b>❓ Word не открывает ссылки на файлы</b></summary>

**Причина:** Word блокирует гиперссылки из внешних источников.

**Решение:**
1. Word → **Файл → Параметры → Центр управления безопасностью → Параметры центра управления безопасностью → Надёжные расположения**
2. Добавьте UNC-путь или букву диска (`\\server\share` или `Z:\`)
3. В разделе «Защита от фишинга» снимите **«Запретить гиперссылки из внешних источников»**

</details>

<details>
<summary><b>❓ Как добавить свои ключевые слова</b></summary>

Меню **Инструменты → Редактировать keywords.txt** — откроется файл, добавьте слова (по одному на строку) и сохраните. Затем **Инструменты → Перезагрузить ключевые слова**.

</details>

<details>
<summary><b>❓ RAR-архивы не распаковываются</b></summary>

Установите **7-Zip** или **WinRAR**:

```powershell
winget install 7zip.7zip
```

Программа автоматически найдёт `7z.exe` / `unrar.exe` в стандартных путях.

</details>

<details>
<summary><b>❓ Сканирование слишком медленное</b></summary>

Включите режим **📝 Только имена** — проверяются только имена файлов (без извлечения содержимого). Скорость возрастает в десятки раз.

</details>

<details>
<summary><b>❓ Программа упала — что делать</b></summary>

1. Откройте **⚠ Ошибки** — там будут детали
2. При следующем запуске сканирование продолжится с **чекпоинта**
3. Если чекпоинт повреждён — **Инструменты → Сбросить чекпоинт**

</details>

<details>
<summary><b>❓ Работает ли на Linux / macOS</b></summary>

**Нет** — программа использует Windows-специфичные API:
- `WMI` для информации о дисках
- `ctypes.windll` для атрибутов файлов
- `WNetGetConnectionW` для UNC-путей
- `winsound` для звука

Планируется кроссплатформенная версия, но пока — только Windows.

</details>

## 🐛 Известные ограничения / Known Limitations

| Ограничение | Комментарий |
|---|---|
| **Только Windows** | Используются WMI, windll, winsound |
| **EasyOCR требует ~2 ГБ** | Torch + модели — скачиваются при первой установке |
| **RAR без 7-Zip/WinRAR** | Не распаковывается |
| **volatility3 — внешний** | Может требовать отдельной установки |
| **OCR на больших PDF** | Может быть медленным (по 1 странице за раз) |
| **Чекпоинт только для одной цели** | При смене папки чекпоинт сбрасывается |
